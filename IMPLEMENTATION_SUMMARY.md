## 🔧 Технические характеристики

### API Integration
- **Сервис:** Open Elevation API (https://api.open-elevation.com)
- **Метод:** POST /api/v1/lookup
- **Батч размер:** 100 точек
- **Таймаут:** 30 секунд
- **Retry:** 3 попытки с задержкой

### Лимиты
- **Макс. площадь:** 50 км²
- **Макс. точек сетки:** 5000
- **Макс. точек профиля:** 500
- **TTL кэша:** 24 часа

### Производительность
| Площадь | Время обработки | Точек в сетке |
|---------|----------------|---------------|
| < 1 км² | 2-5 сек | 100-400 |
| 1-10 км² | 5-15 сек | 400-2000 |
| 10-50 км² | 15-30 сек | 2000-5000 |

## 📊 Визуализация

### Тепловая карта высот (Leaflet.heat)
```
Цветовая схема:
🟦 Синий   → Низкие точки рельефа
🟩 Зеленый → Средние высоты
🟨 Желтый  → Повышенные участки  
🟧 Оранжевый → Высокие точки
🟥 Красный → Максимальные высоты
```

### График профиля высот (Plotly.js)
```
Элементы графика:
📈 Коричневая линия с заливкой - профиль рельефа
📊 Синяя пунктирная линия - линия полета дрона (горизонтальная)
📏 Ось X - расстояние вдоль маршрута (км)
📐 Ось Y - высота над уровнем моря (м)
🎯 Hover - детальная информация о точке
```

## ⚠️ Известные ограничения

1. **Площадь территории:** максимум 50 км² для запросов elevation
2. **Open Elevation API:** может быть недоступен (бесплатный сервис)
3. **Кэш в памяти:** очищается при перезапуске сервера
4. **Точность высот:** зависит от точности API (~30 метров)

## 💡 Рекомендации по использованию

### Когда использовать учет рельефа:
✅ Горная местность с большими перепадами высот  
✅ Холмистая местность  
✅ Территории с неравномерным рельефом  
✅ Когда критична безопасная высота над землей

### Когда можно не использовать:
❌ Абсолютно плоская местность (город, поле)  
❌ Очень большие территории (>50 км²)  
❌ Когда нужна быстрая обработка  
❌ Когда Elevation API недоступен
