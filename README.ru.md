# 🚁 Drone Route Planner

**Автоматизированная система планирования маршрутов полёта БПЛА для аэрофотосъёмки**

[![Docker](https://img.shields.io/badge/Docker-Ready-2496ED?logo=docker)](https://www.docker.com/)
[![Node.js](https://img.shields.io/badge/Node.js-v18+-339933?logo=node.js)](https://nodejs.org/)
[![Python](https://img.shields.io/badge/Python-3.11+-3776AB?logo=python)](https://www.python.org/)

Веб-приложение с открытым исходным кодом для планирования миссий аэрофотосъёмки с автоматическим расчётом маршрута, учётом рельефа местности и поддержкой популярных моделей дронов.

![Интерфейс Drone Route Planner](https://via.placeholder.com/800x400?text=Drone+Route+Planner+Interface)

---

## ✨ Основные возможности

### 🗺️ Планирование маршрута
- **Алгоритм «газонокосилки» (Boustrophedon)** — автоматическая генерация маршрута с настраиваемым перекрытием
- **Рисование территории** — возможность нарисовать полигон любой формы на интерактивной карте
- **Учёт рельефа местности** — интеграция с Open-Elevation API для планирования полётов с учётом высот
- **Поддержка множества дронов** — 6 популярных моделей с точными характеристиками камер

### 📊 Метрики миссии
- Площадь покрытия, длина маршрута и расчётное время полёта
- Количество снимков и требуемый объём памяти
- Оценка использования батареи с коэффициентом безопасности
- Расчёт разрешения на местности (GSD)

### 📤 Экспорт и визуализация
- Экспорт маршрутов в форматы **GeoJSON**, **KML** и **KMZ**
- Интерактивная симуляция полёта с элементами управления
- Визуализация профиля высот рельефа
- Отображение погодных условий через OpenWeatherMap API

### 👤 Управление пользователями
- Регистрация и аутентификация пользователей (JWT)
- Сохранение и управление миссиями
- Личный кабинет с историей миссий

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/your-username/drone-route-building.git

   ```

2. **Настройте переменные окружения**

   ```bash
   cp .env.example .env
   ```


4. **Откройте приложение**

   Перейдите в браузере по адресу: [http://localhost](http://localhost)

## 📖 Руководство пользователя

### Планирование миссии

1. **Нарисуйте территорию** — используйте инструмент полигона для обозначения области съёмки
2. **Настройте параметры**:
   - Высота полёта (5-400 м)
   - Боковое перекрытие (10-95%)
   - Продольное перекрытие (50-95%)
   - Выберите модель дрона
   - Включите/выключите учёт рельефа
3. **Получите маршрут** — маршрут автоматически рассчитывается при завершении рисования
4. **Просмотрите метрики** — изучите панель с информацией о миссии
5. **Экспортируйте маршрут** — скачайте в формате GeoJSON, KML или KMZ

### Параметры миссии

| Параметр | По умолчанию | Диапазон | Описание |
|----------|--------------|----------|----------|
| Высота полёта | 50 м | 5-400 м | Высота над уровнем земли |
| Боковое перекрытие | 30% | 10-95% | Перекрытие между соседними полосами |
| Продольное перекрытие | 70% | 50-95% | Перекрытие между последовательными снимками |

### Учёт рельефа

При включении этой функции система:
- Получает данные о высотах из Open-Elevation API
- Рассчитывает абсолютную высоту полёта над наивысшей точкой рельефа
- Отображает тепловую карту рельефа на карте
- Показывает подробный профиль высот в модальном окне

## 🧮 Математическая модель

Система использует точные математические формулы для расчёта маршрута:

### Угол обзора камеры
```
FOV_горизонтальный = 2 × arctan(ширина_матрицы / (2 × фокусное_расстояние))
FOV_вертикальный = 2 × arctan(высота_матрицы / (2 × фокусное_расстояние))
```

### Покрытие на местности
```
Ширина_кадра = 2 × высота_полёта × tan(FOV_горизонтальный / 2)
Длина_кадра = 2 × высота_полёта × tan(FOV_вертикальный / 2)
```

### Разрешение на местности (GSD)
```
GSD = (Ширина_кадра × 100) / разрешение_изображения  [см/пиксель]
```

### Эффективный шаг
```
Шаг_боковой = Ширина_кадра × (1 - боковое_перекрытие)
Шаг_продольный = Длина_кадра × (1 - продольное_перекрытие)
```

## 🔧 Разработка

### Запуск без Docker

**Сервис маршрутов (Node.js)**
```bash
cd drone-route-server
npm install
npm start
```

**Сервис авторизации (Python)**
```bash
cd drone-route-auth
python -m venv venv
source venv/bin/activate  # или `venv\Scripts\activate` на Windows
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**Клиент (статические файлы)**
Раздайте директорию `drone-route-client/` через любой статический сервер или Nginx.

### Запуск тестов

```bash
cd drone-route-server
npm test
```
