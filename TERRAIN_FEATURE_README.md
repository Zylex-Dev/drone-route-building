# Функционал учета рельефа местности

## Обзор

Реализован полный функционал для учета рельефа местности при построении маршрута полета дрона, включая:

- ✅ Интеграция с Elevation API для получения данных о высотах
- ✅ Автоматический расчет абсолютной высоты полета на основе максимальной точки рельефа
- ✅ Визуализация рельефа через интерактивную тепловую карту (Leaflet.heat)
- ✅ Интерактивный 2D-график профиля высот (Plotly.js)
- ✅ Модальное окно с детальной информацией о рельефе
- ✅ Оптимизация запросов через батчинг и кэширование
- ✅ Индикатор загрузки при запросе данных о рельефе

## Архитектура решения

### Backend (Node.js + Express)

**Новые файлы:**
- `/drone-route-server/services/elevation-service.js` - сервис для работы с Elevation API
- `/drone-route-server/tests/elevation-service.test.js` - unit-тесты

**Изменения:**
- `/drone-route-server/index.js` - расширен endpoint `/api/calculate-route`
  - Добавлен параметр `enableTerrainFollowing` (boolean)
  - Интеграция с elevation-service
  - Расчет `absoluteFlightAltitude` = max(terrain) + relativeAltitude
  - Возврат `terrainData` в ответе

**Ключевые особенности:**
- **Батчинг запросов**: группировка по 100 точек на запрос к API
- **Кэширование**: Map-based кэш с TTL 24 часа
- **Retry логика**: 3 попытки с задержкой при ошибках
- **Лимиты**: максимум 50 км² территории, 5000 точек сетки

### Frontend (JavaScript + Leaflet + Plotly)

**Новые файлы:**

## Использование

### 1. Включение учета рельефа

В левой панели установите флажок:
```
☑ Учитывать рельеф местности
```

### 2. Построение маршрута

Постройте маршрут как обычно:
1. Нарисуйте полигон территории на карте
2. Задайте параметры полета (высота, перекрытия)
3. Маршрут будет построен автоматически

**При включенном учете рельефа:**
- Появится индикатор загрузки "Загрузка данных о рельефе местности..."
- На карте появится тепловая карта высот (цветовая градация от синего к красному)
- В боковой панели появится карточка "Информация о рельефе"
- Активируется кнопка "Профиль рельефа"

### 3. Просмотр профиля рельефа

Нажмите кнопку **"🏔️ Профиль рельефа"**

Откроется модальное окно с:
- **Интерактивным 2D-графиком**:
  - Коричневая линия: профиль рельефа местности
  - Синяя пунктирная линия: линия полета дрона (горизонтальная)
  - Ось X: расстояние вдоль маршрута (км)
  - Ось Y: высота над уровнем моря (м)

- **Статистикой**:
  - Максимальная высота рельефа
  - Минимальная высота рельефа
  - Перепад высот
  - Абсолютная высота полета

### 4. Интерпретация данных

**Абсолютная высота полета:**
```
absoluteFlightAltitude = maxTerrainElevation + relativeAltitude
```

Где:
- `maxTerrainElevation` - максимальная точка рельефа вдоль маршрута
- `relativeAltitude` - заданная пользователем высота полета (например, 50 м)

**Пример:**
- Максимальная высота рельефа: 245.6 м (над уровнем моря)
- Заданная относительная высота: 50 м
- **Абсолютная высота полета: 295.6 м**

Дрон будет лететь на постоянной высоте 295.6 м над уровнем моря, что обеспечивает минимум 50 м над самой высокой точкой рельефа.

## API Reference

### Backend Endpoint

**POST** `/api/calculate-route`

**Request Body:**
```json
{
  "territory": [{lat: 55.7558, lng: 37.6173}, ...],
  "droneModel": "DJI Matrice 30T",
  "flightAltitude": 50,
  "desiredOverlap": 0.3,
  "forwardOverlap": 0.7,
  "enableTerrainFollowing": true
}
```

**Response (с terrainData):**
```json
{
  "success": true,
  "route": {
    "type": "Feature",
    "properties": {
      "terrainData": {
        "enabled": true,
        "maxTerrainElevation": 245.6,
        "minTerrainElevation": 120.3,
        "absoluteFlightAltitude": 295.6,
        "relativeAltitude": 50,
        "terrainRange": 125.3,
        "isFlat": false,
        "elevationProfile": [{lat, lng, elevation}, ...],
        "elevationGrid": [{lat, lng, elevation}, ...]
      }
    }
  }
}
```

## Технические детали

### Elevation API

**Используемый сервис:** https://api.open-elevation.com/api/v1/lookup

**Формат запроса:**
```json
POST /api/v1/lookup
{
  "locations": [
    {"latitude": 46.24566, "longitude": 6.17081},
    {"latitude": 46.85499, "longitude": 6.78134}
  ]
}
```

**Формат ответа:**
```json
{
  "results": [
    {"latitude": 46.24566, "longitude": 6.17081, "elevation": 372},
    {"latitude": 46.85499, "longitude": 6.78134, "elevation": 1534}
  ]
}
```

### Оптимизация

**Батчинг:**
- Максимум 100 точек на запрос
- Задержка 200ms между батчами

**Кэширование:**
- TTL: 24 часа
- Ключ: округленные координаты (5 знаков после запятой)
- Хранилище: Map (in-memory)

**Лимиты:**
- Максимальная площадь: 50 км²
- Максимум точек сетки: 5000
- Таймаут запроса: 30 секунд
- Retry попытки: 3

### Производительность

**Типичные времена обработки:**
- Малая территория (<1 км²): 2-5 секунд
- Средняя территория (1-10 км²): 5-15 секунд
- Большая территория (10-50 км²): 15-30 секунд

## Возможные проблемы и решения

### 1. Elevation API недоступен

**Проблема:** Сервер возвращает ошибку 500
```
Не удалось получить данные о рельефе: ...
```

**Решение:** 
- Отключите опцию "Учитывать рельеф"
- Постройте маршрут без учета рельефа
- API может быть временно недоступен

### 2. Территория слишком велика

**Проблема:** 
```
Территория слишком велика для учета рельефа (55.3 км²). Максимум: 50 км².
```

**Решение:**
- Уменьшите площадь полигона
- ИЛИ разбейте на несколько миссий
- ИЛИ отключите учет рельефа

### 3. Медленная загрузка

**Проблема:** Долгое ожидание при включенном учете рельефа

**Решение:**
- Это нормально для больших территорий
- Первый запрос медленнее (нет кэша)
- Повторные запросы быстрее благодаря кэшу

### 4. Плоская местность

**Уведомление:** "Рельеф практически плоский (перепад менее 5 метров)"

**Значение:** Учет рельефа не критичен для данной территории, но можно оставить включенным.
