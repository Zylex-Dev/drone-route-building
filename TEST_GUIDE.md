# Руководство по тестированию

## Предварительная подготовка

### 1. Запуск всех сервисов

```bash
# В корне проекта
docker compose up --build
```

Дождитесь успешного запуска всех 4 сервисов:
- ✅ `drone_route_postgres` - База данных
- ✅ `drone_route_auth` - Auth Service (FastAPI)
- ✅ `drone_route_server` - Route Service (Node.js)
- ✅ `drone_route_client` - Frontend (Nginx)

### 2. Проверка работоспособности

```bash
# Проверка PostgreSQL
docker exec drone_route_postgres pg_isready -U droneuser

# Проверка Auth Service
curl http://localhost:8000/health

# Проверка Route Service  
curl http://localhost:3000/health  # (если есть health endpoint)

# Проверка Client
curl http://localhost/
```

## Сценарии тестирования

### Сценарий 1: Регистрация нового пользователя

**Шаги:**
1. Откройте http://localhost
2. Нажмите "Регистрация" в навигационной панели
3. Введите данные:
   - Email: `test-user@example.com`
   - Пароль: `TestPass123` (минимум 8 символов, буквы и цифры)
   - Подтверждение пароля: `TestPass123`
4. Нажмите "Зарегистрироваться"

**Ожидаемый результат:**
- ✅ Сообщение "Регистрация успешна!"
- ✅ Автоматический редирект в личный кабинет
- ✅ Email отображается в навигации

**Проверка в БД:**
```bash
docker exec -i drone_route_postgres psql -U droneuser -d drone_missions -c "SELECT email, created_at FROM users;"
```

### Сценарий 2: Вход существующего пользователя

**Шаги:**
1. Выйдите из системы (кнопка "Выход")
2. Перейдите на страницу входа (http://localhost/login.html)
3. Введите данные зарегистрированного пользователя
4. Нажмите "Войти"

**Ожидаемый результат:**
- ✅ Успешный вход
- ✅ Редирект в личный кабинет
- ✅ Email в навигации

**Проверка токена:**
```javascript
// В консоли браузера (F12)
localStorage.getItem('drone_auth_token')
// Должен вернуть JWT токен
```

### Сценарий 3: Построение и сохранение миссии

**Шаги:**
1. Убедитесь что вы авторизованы
2. Перейдите на главную страницу (http://localhost)
3. Нарисуйте полигон на карте:
   - Выберите инструмент "Polygon" (слева)
   - Нарисуйте область (минимум 3 точки)
   - Завершите рисование (двойной клик)
4. Настройте параметры:
   - Высота: 50м
   - Боковое перекрытие: 30%
   - Продольное перекрытие: 70%
   - Модель: DJI Matrice 30T
5. Дождитесь автоматического построения маршрута
6. Нажмите кнопку "💾 Сохранить миссию"
7. Введите данные:
   - Название: "Тестовая миссия"
   - Описание: "Тестирование сохранения"
8. Нажмите "Сохранить"

**Ожидаемый результат:**
- ✅ Маршрут построен и отображён на карте
- ✅ Кнопка "Сохранить миссию" видна
- ✅ Модальное окно открылось
- ✅ Сообщение "Миссия успешно сохранена!"
- ✅ Предложение перейти в личный кабинет

**Проверка в БД:**
```bash
docker exec -i drone_route_postgres psql -U droneuser -d drone_missions -c "SELECT name, drone_model, flight_altitude FROM missions;"
```

## Тестирование API напрямую

### Регистрация через curl

```bash
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "api-test@example.com",
    "password": "SecurePass123"
  }'
```

### Вход через curl

```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "api-test@example.com",
    "password": "SecurePass123"
  }'
```

### Получение списка миссий

```bash
# Сохраните токен из предыдущего запроса
TOKEN="<ваш_токен>"

curl -X GET "http://localhost:8000/api/missions?limit=10&offset=0" \
  -H "Authorization: Bearer $TOKEN"
```

## Типичные проблемы и решения

### 1. Ошибка "Email уже зарегистрирован"

**Решение:** Используйте другой email или очистите БД:
```bash
docker compose down -v
docker compose up
```

### 2. Токен истёк (401 Unauthorized)

**Решение:** Войдите заново. Токены действительны 7 дней.

### 3. Миссия не сохраняется

**Проверьте:**
- Построен ли маршрут (кнопка "Сохранить" должна быть видна)
- Нарисован ли полигон на карте
- Открыта ли консоль браузера (F12) для просмотра ошибок

### 4. CORS ошибки

**Проверьте:**
```bash
# Убедитесь что все сервисы запущены
docker compose ps

# Проверьте config.js
cat drone-route-client/js/config.js
```
